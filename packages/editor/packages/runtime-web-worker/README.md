# @8f4e/runtime-web-worker

Web Worker execution loop and message protocol for 8f4e programs. The page-side editor integration, configuration, and lifecycle live in
[`@8f4e/editor-plugin-worker-runtime`](../../plugins/worker-runtime/README.md).

Validate with `npx nx run @8f4e/runtime-web-worker:build|test|typecheck`.
