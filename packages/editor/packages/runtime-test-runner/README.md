# @8f4e/runtime-test-runner

Dedicated worker that executes compiled test entries and returns assertion outcomes for 8f4e programs. The page-side editor integration, configuration, and lifecycle live in
[`@8f4e/editor-plugin-test-runtime`](../../plugins/test-runtime/README.md).

Validate with `npx nx run @8f4e/runtime-test-runner:build|test|typecheck`.
